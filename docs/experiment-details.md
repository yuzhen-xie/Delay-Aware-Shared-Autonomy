# 实验实施与数据记录细则

本文档规定本工程的可执行流程、信号定义和证据要求。配置文件中的数值是当前实现的默认值；它们不能代替设备标定或原始记录。新运行均生成新的版本与数据摘要。合成轨迹、模拟操作者和真实参与者分别标记来源，禁止合并为同一种实验证据。

最短复现入口见 [逐图运行说明](figure-recipes.md)。模型、精炼、参与者和视觉接口分别见 [意图模型](intent-model.md)、[技能精炼](skill-refinement.md)、[参与者协议](human-study.md) 和 [感知与场景](perception-scenes.md)。[参数表](parameters.md) 对应默认配置；每次执行应另存本次解析后的参数表。

## 1. 平台、任务与变量

控制器采用机器人基坐标系 `base`，位置单位 m，时间 s，力 N。候选目标固定为三个；一次试验的真实目标由任务指令给定，控制器只接收候选位置和操作者信号。真实目标仅用于训练标签、任务评定和离线指标，不能用于在线目标推断。抓取完成后，物体身份由任务状态机或独立抓取事件提供。

| 变量 | 类型/空间 | 定义 |
| --- | --- | --- |
| `q`, `dq` | 连续 `R^6` | UR10/UR10e 关节角 rad、角速度 rad/s；设备接口记录 |
| `s_t=[p_t,v_t]` | 连续 `R^6` | TCP 平移状态；意图/仿真控制使用的状态 |
| `s_observed` | 连续 `R^6` | 人实际看见、带源时间戳的历史状态 |
| `u_H`, `F_H` | 连续 `R^3` | 原始主端力、卡尔曼滤波后的力 |
| `a_H` | `R^3`, 范数 0 或 1 | 原始力的单位方向；零力映射为零 |
| `G` | 分类 `{0,1,2}` | 候选目标索引，顺序在场景文件中固定 |
| `P_g`, `O_j` | 连续 `R^3` | 目标抓取中心、障碍球中心，均在 `base` |
| `r_j` | 正实数 | 障碍球半径；`O_j` 不表示表面点 |
| `z`, `mu`, `logvar` | 连续 `R^8` | 行为特征与对角高斯编码参数 |
| `posterior` | 三维概率单纯形 | 目标概率，总和为 1 |
| `Sigma` | 对称正定 `R^(3×3)` | 位置分布协方差，单位 m² |
| `alpha`, `lambda`, `c_A`, `c_H`, `rho` | `[0,1]` 标量 | 仲裁、风险混合、置信代理和相对能量移除量 |
| `phase` | 离散 `{0,1,2,3}` | 抓取、抬升、运输/放置、完成 |
| `E`, `W`, `S`, `spill` | 实数，单位 J | 储能、输出功、输入能量、容量溢出 |

`robotics/kinematics.py` 使用六关节标准 DH 链。UR10 的 `a=[0,-.612,-.5723,0,0,0] m`，`d=[.1273,0,0,.163941,.1157,.0922] m`；UR10e 使用单独的参数集。两者的扭转角均为 `[pi/2,0,0,pi/2,-pi/2,0]`。这是标称几何模型；实机需要厂家标定、TCP 偏置和独立检查点。Jacobian 为 `6×6`；当前 RTDE 适配器保持工具姿态，只控制平移，不把平移任务称为完整六自由度接触操作。

仿真采用 `m=1.2 kg`、`b=12 N s/m` 的三维点质量，积分周期 1 ms，决策周期 20 ms。它没有 UR10 连杆惯量、关节摩擦、夹爪接触和全臂碰撞动力学。机器人型号与仿真动力学属于不同层面的模型。

## 2. 抓取放置任务及复杂度

默认场景包含三个可混淆目标、共同放置区和两个障碍。基准 TCP 初始位置为 `(0.16,-0.10,0.46)`；目标为 `(0.56,-0.25,0.12)`、`(0.64,0,0.12)`、`(0.55,0.24,0.12)`；放置位置为 `(0.80,0.29,0.12)`。障碍中心/半径为 `(0.43,0,0.23)/0.075` 和 `(0.35,-0.28,0.19)/0.060 m`。这些是基准设计坐标，不是已标定实物坐标。

约束场景清单采用 `0.04×0.04×0.06 m` 的提议物体包络；真实物体尺寸须逐件测量后替换。该包络用于静态布局筛选，运行时仿真的碰撞模型仍只有半径 `0.025 m` 的 TCP 球。不能以此替代持物碰撞、连杆碰撞和夹爪可达性验证。

抽象状态机要求：TCP 在目标中心 `0.045 m` 内、速度低于 `0.18 m/s`，连续保持 `0.16 s` 后抓取；抓错目标立即失败。抬升门限为配置抬升高度减 `0.05 m`，随后运输到放置点；距离小于 `0.055 m` 且满足相同速度/驻留条件后完成。仿真默认超时 `18 s`；设备和提议人因协议采用 `60 s`，两种预算必须分别记录，不混合比较完成时间。真实抓取/释放成功须由独立事件、视频或夹爪传感器标注，不能只以 TCP 到达判定。

每个 1 ms 积分步使用上一位置到下一位置的线段，计算线段到每个障碍中心的最短距离，再减去障碍与 TCP 半径；不大于零判为碰撞。越过配置的 Cartesian 工作区也终止。失败保留原始轨迹、失败原因和已用时间；完成时间记缺失，同时将失败纳入成功率。成功条件下的完成时间存在选择效应，必须与失败比例共同解释。

任务中的人工作用是选择目标和在不确定/延迟反馈下提供纠偏。它能检验目标推断与权重切换，却不能代表所有复杂空间操作。扩展验证采用未见目标布局、较大扰动、多障碍和额外通信延迟；真实遮挡、目标变更、姿态约束、插接/接触任务需另外登记设备接口和成功判据，当前结果不能外推到这些能力。

## 3. 启动数据、模型和实际训练目标

默认启动/验证/测试示范数为 `20/6/12`，比例为 `20/38、6/38、12/38`，分别为约 `52.63%、15.79%、31.58%`。快速检查使用 `20/6/6`。默认生成器是带端点约束的五次多项式合成示范，不是参与者数据。每段速度区间 `[0.16,0.24] m/s`，最短 `0.45 s`，侧向扰动标准差 `0.008 m`，原始力噪声 `0.15 N`；所有这些数值均可配置。清单列出每个文件、场景、目标、操作者、种子、采样数及 SHA-256。

真实数据采用相同 NPZ 契约和显式 `splits.json`。在特征提取前按操作者划分；事件 ID、操作者及重复信号不能跨训练、验证和测试。真实人数据的实际比例应由清单计算，不能强行写成合成数据比例。配置、训练曲线、数据清单和模型摘要一起保留。

`train-data` 将声明的数据集快照保存到输出目录；`intent-recordings` 直接评估测试分区中的已录动作与实际观测，不重新模拟操作者，也不向已对齐信号再次注入延迟。`intent` 则是独立的闭环仿真路线。测量数据的延迟元数据用于分组，具有源时间数组时由时间戳计算实际年龄；只有名义延迟时明确标记其来源，不能把名义年龄当成测量值。

默认 cVAE 编码输入维度为 25，隐藏层 `64/64`、SiLU、潜变量 8；解码输入 27，隐藏层 `64/64`，输出动作 3 和候选偏差 3。分类器 `f_cls` 是 `27→64→3` 的 SiLU MLP，使用前一时刻潜变量均值，输出 softmax 目标先验。`p(z)=N(0,I_8)`。推断初始化使用零先验均值。所有候选偏差均可由已知候选参考轨迹计算，不读取真实目标。

本版默认 `joint_elbo` 的实际反向传播目标为：

```text
reconstruction_nll = action_nll + deviation_nll
loss = reconstruction_nll + kl_divergence
```

似然为固定单位方差的高斯特征重建，坐标求和、批次均值，省略常数。两个重建分量和 KL 都在训练日志单独保存，审计绑定模型校验值。偏差是确定性派生特征，不构成新的独立观测。`legacy_objective.yaml` 明确保留旧加权目标；没有训练审计的模型目标为 `unrecorded`。修改配置或重新训练均不能证明旧模型使用过当前目标。完整数学定义、预处理、优化器、LSTM、Transformer 和 DMP 设置见意图模型文档。

初始 TP-HSMM 使用起点/目标/放置点三个任务坐标系，旋转均为单位矩阵；完整位置轨迹按归一化时间重采样 140 点。默认 7 状态、顺序无跳跃转移、时间等分初始化、6 轮显式时长 EM，协方差特征值下限 `1e-5 m²`、时长标准差下限 `1.5` 个重采样点。任务高斯在世界系用精度乘积组合；MAP 时长序列加 6 维位置/速度 LQT 生成轨迹，控制代价 `0.01 I`。默认使用该轨迹的局部协方差；`online.yaml` 可启用因果状态-年龄滤波不确定性，但执行参考仍为阶段约束的 LQT 路径。不能把默认离线路径游标描述成在线 HSMM 状态后验。

## 4. 示范采集、筛选和精炼

每个训练重复使用同一个初始模型比较 C1/C2/C3，采集反馈单向延迟 `0.8 s` 的试验。逐次保留成功和失败记录，再依采集顺序选取前 20 条成功示范；不得按后续评估成绩选择示范。输入信号包括时间、TCP 位置/速度、原始主端力、实际显示的状态、阶段、目标、场景、独立结果标注及来源。完整试验还保留网络源时间、滤波力、目标后验、权重、参考和执行力、净空及能量账本。

筛选要求正确物体完成放置、无碰撞/越界、时间戳有效、轨迹扫掠检查通过、终点放置误差和已用时间符合阈值；拒绝原因逐条输出。去重使用事件 ID 和信号摘要；测量数据必须有结果标注，不能把成功标签当成模拟器推断。录制失效、设备中断、撤回等排除也应在采集台账单独记录，不能在失败记录中无痕删除。

更新方法为从统一时间分段初始化重新拟合原始数据与新增数据的并集，不是只拟合新 20 条，也不是未经实现的在线梯度增量法。默认每条原始/新增示范权重均为 1；原始 20 条加新 20 条时总质量各占一半。模型保存全部训练 ID、权重、信号/记录摘要、拟合参数、时长、EM 历史及初始化方法。cVAE 和分类器在此阶段冻结。

配额不足时必须报告尝试数和接受数。诊断性评估可继续保存，但不进入固定预算比较或相应显著性检验。完整计划为 10 个独立训练重复，每模型每场景 100 条自主试验；100 条测试轨迹先汇总为该模型的均值，统计单位是训练重复。若多个重复共用启动数据，只能作条件于该启动数据的推断，不能宣称启动数据独立。

## 5. 场景随机化、泛化和调参

主种子默认 `20261014`。原生成器按 `train→validation→test`、索引递增生成，种子 `seed+10000*split_index+j`。所有目标、起点、放置点和障碍共享 `xyz` 平移，每轴均匀 `±0.025 m`，z 再乘 0.25。新场景在 xy 每轴独立加带符号 `[0.05,0.15] m` 扰动；`wider` 放大 1.6 倍。目标随后裁剪到 x `[0.30,0.78]`、y `[-0.42,0.42]`，所以实际位移必须由清单计算，不能宣称每个目标恰好移动上述距离。新场景增加一个障碍，多障碍场景增加三个，位置见保存的清单。

旧的直接采样过程保存在轨迹的场景元数据中。新的 `scene-manifest` 使用版本化拒绝采样：`SeedSequence([master_seed,index,attempt])` 产生子种子，逐目标编号、逐尝试生成；检查包络/工作区、目标间隔、障碍相交及标称 TCP 路径净空。接受布局与拒绝原因均保存，SHA-256 检查后可重放。约束只保证这些静态几何条件，不保证学习策略成功或 UR10 全臂可行。两种生成器不能在结果中混称。

`generalization` 冻结共同评估清单，比较未精炼模型及 `5/10/20` 条首次成功前缀；额外 40 条必须先取得足额示范，再显式扩展预算。场景含原布局分布、常规扰动、扩大扰动、多障碍。逐重复输出原始试验和所有预算结果，既报告成功率也报告参考误差、净空和失败类型；参考误差是模仿一致性，不是独立任务成功指标。保持验证与测试分离，新增场景禁止回流调参。

`sensitivity.yaml` 规定验证集上的单因素候选网格：`beta=1/3/5`、`K_lambda=5/10/20`、距离阈值、滤波 Q/R、`gamma_j` 和场系数。它是提议的调参实验，不是默认参数已被优化的证据。应保存全部候选结果及冻结日期，再运行测试。`validation-sweep` 不读取测试示范，不自动将逐因素最优值组合成未经验证的新最优模型。

## 6. 延迟、滤波与仲裁的实际实现

主实验反馈单向延迟为 `0、0.4、0.8、1.5 s`，命令通道为零延迟；这些数值不能称为双向各自延迟。双向压力测试另加 `0.4 s` 命令延迟，抖动测试使用均匀 `±0.2 s`，截断负延迟。时间戳缓冲器取查询时间减延迟之前的最后一个样本，零阶保持；不使用未来状态，也不回退到已过期包。启动时保持初始观测。到达命令携带主端实际看到的状态和源时间，推断对齐这个状态；`feedback_age` 记录执行时刻与该源时刻之差，因此可能包括反馈、命令和采样保持的总年龄。逐次记录源时间与决策时间，比仅给名义延迟更可核查。

力滤波模型为 `x_(k+1)=I x_k+w_k`、`y_k=I x_k+v_k`，状态/观测均为三维力。`Q=0.08 I N²/sample`、`R=0.8 I N²`、`P_0=I N²`、均值 `x_0=0`，每 20 ms 更新，协方差使用 Joseph 形式；Q 是每次更新的离散方差，更改频率不能直接声称噪声密度不变。实际数据可用静态力段估计 R、动态标定段估计 Q，验证集选择后冻结，保存残差和创新统计；默认数值尚不代表这种标定已完成。

风险默认使用到障碍中心的距离 `ell=min_j||p_observed-O_j||`；表面净空另存为 `||p-O_j||-r_j-r_TCP`。`surface_risk.yaml` 是独立扩展，不能将两种距离的阈值直接混用。`lambda=sigmoid(K_lambda*(ell-(d_min+d_max)/2)/(d_max-d_min))`，默认 `d_min=.08 m`、`d_max=.25 m`、`K_lambda=10`，后者无量纲，越大过渡越陡。这里接近障碍时减小场引导权重、增加人工比重。高斯斥力在中心处为零，不能作为全局避障屏障或安全保证。

场系数 `beta_1=motion.attractive_weight=1`、`beta_2=motion.repulsive_weight=1` 是显式乘子；吸引增益 `22 N/m`、排斥增益 `.20 N m`、宽度 `.11 m`、每障碍限幅 `8 N`。这些乘子不是新增已测量的历史数值；无额外乘子时等价为 1。`gamma_j=.012 s/N` 为全体共用的力变化敏感度；`epsilon=1e-6`。全部参数的单位、默认值及来源在参数表中列出。

`c_A` 根据位置协方差迹在 `[3e-5,.006] m²` 间线性递减。`c_H=(1-rho)*exp(-gamma_j*mean(||Delta F_H||/Delta t))`，窗口 15 个决策样本，初始上一力为零。它是命令平滑度与能量透明性的代理，不是测得的人类能力。C3 的 `alpha=c_A/(c_A+c_H+epsilon)` 是相对混合权重；当两者都很低时不能解释为绝对可靠性。C1 旁路运动共享并置 alpha=0；C2 使用 c_A；C4 固定 `.5`。`C3_guarded` 的低置信缩放和纠偏限权属于另外的压力测试扩展，不能替换 C3 后沿用原标签。

## 7. 能量累积与无源性范围

仿真每 1 ms 使用隐式中点法，`v_mid=(2*m*v+dt*F)/(2*m+dt*b)`，机器人输出功为 `W=dt*F·v_mid`。人端输入只计正功 `S=eta*dt*max(F_H·v_h,0)`，`eta=.9`。输入后容量截断，输出超过可用储能时将力投影到相应凸功约束集；负输出功返还储能，超过 `8 J` 的部分记入 spill。共享控制初始 `1 J`，纯自主执行初始 `8 J`；自主执行原始人力和人端能量输入均为零。

累积恒等式为 `E_0 + sum(S) - sum(W) - sum(spill) - E_t`；保存每步残差并检查非负储能。`rho=clip(sum(removed_positive_work)/max(sum(nominal_positive_work),1e-12),0,1)`，求和窗口最近 `1 s`，初始 rho=0。当前步结果供下一决策使用。模拟人端速度采用合成设备关系，并非实测主端速度；真实系统必须读设备速度，不能沿用该代理证明物理交互无源性。

`ThreePortTank` 的三路分配仅是移除机器人功的诊断份额，权重正比 `(1-alpha)*(1-rho_previous)、alpha、1-lambda`。独立 `MultiportPassivity` 模块能对三个实际输入 effort/flow 端口分别修改力或速度，并有采样能量预算测试；它尚未完成设备专用 PC1/PC2/PC3 的整网部署认证。控制器边界的离散能量不等式、持样端口预算、完整带延迟人机网络的稳定性是不同论断，不能相互替代。

## 8. 感知与实机接口

仿真显式假设清单内所有目标/障碍的几何已知且静止；没有感知噪声、漏检或遮挡。新增可执行视觉管线采用校准后、深度对齐的 RGB 区间分割和最大连通域，适用于有颜色标识的台架目标。它不是未经记录的神经检测器。深度按标定尺度换算 m，去除无效/越界像素，用稳健深度和针孔内参反投影，再以 `T_base_camera` 转入机器人系。球形障碍通过已知半径拟合获得中心，或使用标记点加经测量偏置；可见表面点的中值不能直接冒充中心。

默认任务前采集一次、检查并冻结场景快照。在线模式输出带时间和序号的新快照，但当前工作站控制器不自动订阅它；接入在线更新需处理帧版本、失效超时、漏检和障碍关联后再验证。未知环境不受当前势场保证。相机内外参、深度尺度、中心拟合残差、独立检查误差及具体检测阈值必须随真实设备试验保存。详见感知文档和接口示例。

Windows 工程通过 ur-rtde 接收 UR10 状态；设备型号/IP、标定、工具偏置、速度/力限制均由本地配置填写。主端桥接 UDP 报文包含递增序号、设备时间、基坐标三维力/速度、使能和夹爪事件。七自由度主端具体 SDK 需要设备型号匹配，当前通用接口不等于该型号 SDK 已验证。默认只采集，显式 `--execute` 才使能移动。Windows 的 20 ms 循环不能称为已达到硬实时 1 kHz 物理无源控制。

## 9. 人因、统计与结果生成

公开协议规定匿名试验编号、练习步骤、条件顺序、排除和停止规则。计划参与者数为 20；分析仅依赖匿名编号、试验记录和量表分数，研究登记与人员身份资料独立保管。运行表区分实验试次和练习试次，记录实际完成的条件及中止原因；统计汇总真实纳入数，不把计划人数当成已完成样本量。

统计先在每个参与者/模拟操作者/训练重复内汇总重复试验，再比较同单位配对差。采用双侧符号翻转置换检验；小样本穷举，大样本固定种子 Monte Carlo，报告实际算法、样本数和精度。连续效应报告配对均值差、标准化配对效应 dz、按单位配对 bootstrap 95% CI。分母退化或独立单位不足时保留缺失，不输出虚假精度。符号翻转要求差值在零假设下可交换且相互独立；它不能自动修复有偏条件顺序或缺失数据。

意图、任务表现、NASA-TLX、学习实验分别定义比较家族；一个家族内包含预先列出的所有方法、延迟、指标/场景，用 Holm 校正。每条比较保存原始 p、调整 p、配对单位 ID、缺失数、效应和 CI。完整表是输出的一部分，不只提供星号。完成时间和 EPT 的缺失机制必须报告；NASA-TLX 仅读取真实六分量评分，明确 performance 量表方向后计算等权 RTLX，不从运动指标或模拟操作者生成问卷。
